# Как установить .ipa на iPhone (бесплатно)

## Способ: AltStore

### Шаг 1: Установи AltStore на компьютер
1. Скачай AltServer: https://altstore.io
2. Установи и запусти AltServer
3. Подключи iPhone к компьютеру USB-кабелем
4. В AltServer нажми "Install AltStore" → выбери свой iPhone
5. Введи Apple ID и пароль (обычный, не Developer)

### Шаг 2: Установи AltStore на iPhone
1. Открой AltStore на iPhone
2. Если попросит "Доверять разработчику" — зайди в Настройки → Основные → Управление устройством → выбери свой Apple ID → Доверять

### Шаг 3: Скачай .ipa
1. Зайди в репозиторий: https://github.com/d15621055-boop/KsyushaApp
2. Вкладка "Actions" → последняя сборка → внизу "KsyushaApp-ipa" → скачай

### Шаг 4: Установи .ipa
1. Перекинь .ipa файл на iPhone (через AirDrop, почту, или iTunes File Sharing)
2. Открой AltStore → нажми "+" вверху справа
3. Выбери скачанный .ipa
4. Готово!

**Важно:** AltStore нужно обновлять раз в 7 дней. Подключи iPhone к компьютеру с AltServer и нажми "Refresh All".
